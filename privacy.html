最終更新日: 2026年10月8日

1. 本アプリについて

dog-shorts-uploader は、開発者本人が自身のYouTubeチャンネルに動画を投稿するための個人用ツールです。第三者にサービスを提供するものではありません。

2. 取得する情報

Googleアカウントの認可(YouTube動画のアップロード権限)を通じて、開発者本人のアカウントのアクセストークンを取得します。それ以外の個人情報を取得・収集することはありません。

3. 情報の利用目的

取得したアクセストークンは、開発者本人のYouTubeチャンネルへ動画をアップロードする目的にのみ使用します。

4. 情報の保管・共有

アクセストークンは開発者本人のコンピュータ内にのみ保存し、外部のサーバーへの送信、第三者への提供・販売・共有は行いません。

5. YouTube API Services

本アプリはYouTube API Servicesを利用しています。利用にあたり、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。

6. 権限の取り消し

付与した権限は、Googleアカウントの権限管理ページからいつでも取り消せます。
